# 🛍️ The Bargain Boutique CMS

A professional **Consignment Management System** built on **Google Sheets** and **Google Apps Script**.

The Bargain Boutique CMS is designed to provide a modern application experience while using Google Sheets as the underlying database.

---

## Features

- Inventory Management
- Consignor Management
- Sales Processing
- Payment Tracking
- Dynamic Consignor Statements
- Dashboard & KPI Reporting
- Role-based Security (planned)
- Automated ID Generation
- Google Workspace Integration

---

## Technology Stack

| Layer | Technology |
|--------|------------|
| Database | Google Sheets |
| Backend | Google Apps Script (V8) |
| Frontend | HTML5, CSS3, Vanilla JavaScript |
| UI | Single Page Application (SPA) |
| Development | VS Code |
| Source Control | GitHub |
| Apps Script Sync | clasp |
| CI/CD | GitHub Actions |
| Code Quality | ESLint + Prettier |
